# E-Commerce Sales Analytics Dashboard

## About the Project

This project analyzes e-commerce sales data to understand revenue, profitability, product performance, regional sales, and customer segments. Excel was used for data cleaning and preparation, SQL Server for database organization, and Power BI for dashboard development.

## Tools & Technologies

- **Microsoft Excel:** Data cleaning, preparation, and validation
- **SQL Server:** Database and table creation
- **Microsoft Power BI:** Interactive dashboards, KPI reporting, and data visualization

## Project Workflow

1. Reviewed the raw e-commerce datasets.
2. Cleaned and prepared the order data in Excel.
3. Checked duplicate records, missing values, and data consistency.
4. Created database tables in SQL Server.
5. Developed an interactive Power BI dashboard.
6. Analyzed sales and profit across regions, product categories, and customer segments.

## Dataset

The project includes data related to:

- Orders and transactions
- Customer details and segments
- Product information and categories
- Return records

Both raw and cleaned working datasets are included in the repository.

## Dashboard Analysis

The dashboard focuses on:

- Total sales and profit
- Regional sales performance
- Product category performance
- Customer segment analysis
- Key performance indicators (KPIs)

## Key Findings

Based on the current analysis:

- **Total Sales:** Approximately 86.46 million
- **Total Profit:** Approximately 16.99 million
- **Highest-Revenue Category:** Sports
- **Highest-Revenue Region:** North

Amounts are presented in the dataset's recorded currency.

## Data Cleaning Notes

Data preparation included checking duplicate records, missing values, and sales-related fields. Negative quantities were identified for review rather than automatically changed, as they may require further investigation before drawing business conclusions.
