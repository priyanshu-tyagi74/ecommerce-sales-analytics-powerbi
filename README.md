# E-Commerce Sales Analytics Dashboard

## Project Overview
This project analyzes e-commerce sales data using Excel, SQL Server, and Power BI to understand sales performance, profitability, customer trends, product performance, and order operations.

## Tools & Technologies
- **Excel:** Data cleaning, validation, and preparation
- **SQL Server:** Database creation, table structure, and data validation
- **Power BI:** Interactive dashboard, KPI reporting, and data visualization

## Project Workflow
1. Reviewed raw e-commerce datasets.
2. Cleaned and validated order, customer, product, and return data.
3. Used Excel to match and combine related data where required.
4. Created SQL tables to organize the datasets.
5. Developed an interactive Power BI dashboard to explore business performance.

## Dataset
The project contains order transactions, customer details, product information, and return records.

## Files Included
- `Ecommerce_Analytics_DS unclean.xlsx` — Raw dataset
- `Book1 (AutoRecovered).xlsx` — Cleaned working dataset
- `SQLQuery1.sql` — SQL database and table creation script
- `e-commers executive2.pbix` — Power BI dashboard
- Dashboard screenshot — Visual preview

## Current Status
Data validation is in progress. Negative quantities and cost-validation logic are being reviewed before the dataset is finalized.

## Objective
To demonstrate practical skills in data preparation, SQL database design, data validation, business intelligence, and dashboard development.
